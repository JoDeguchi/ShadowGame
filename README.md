# Shadow Walker（C++ / DxLib）

敵の視界（扇形）を避け、影のマスを渡り歩いてゴールを目指すトップダウン・ステルスゲームです。全3ステージ。

## 遊び方

| 操作 | 内容 |
|---|---|
| 矢印キー / WASD | 移動 |
| Shift（押している間） | 忍び足（遅くなるが、影の中なら絶対に見つからない） |
| R | ステージをやり直す |
| Enter / Space | 決定 |
| Esc | 終了 |

- 黄色い扇形が敵の視界です。壁で遮られます。
- 視界に入ると画面下の「発見度」が上がり、満タンで失敗です。視界から外れれば下がります。
- 暗いマス（影）にいると視界から隠れます。ただし**歩いたまま敵に36px以内まで近づくと気づかれる**ので、近くを通るときは Shift で忍び足にします。
- 緑のマスがゴールです。

## ビルド手順（Visual Studio）

1. DxLib をダウンロードして展開します（Windows 用 VisualStudio 向け）。
2. 「Windows デスクトップ アプリケーション」の空のプロジェクトを作り、`main.cpp` を追加します。
3. プロジェクトのプロパティで次を設定します。
   - C/C++ → 全般 → 追加のインクルードディレクトリ：DxLib の `プロジェクトに追加すべきファイル_VC用` フォルダ
   - リンカー → 全般 → 追加のライブラリディレクトリ：同じフォルダ
   - C/C++ → コマンドライン → 追加のオプション：`/utf-8`（日本語表示に必要）
   - リンカー → システム → サブシステム：Windows
   - C++ 言語標準：C++17 以上
4. ビルドして実行します。

## ステージの編集

`main.cpp` の `STAGES` に文字で書かれています。1行は 8文字 × 3 の 24文字、18行です。

| 記号 | 意味 |
|---|---|
| `#` | 壁 |
| `.` | 明るい床 |
| `s` | 影 |
| `S` | スタート |
| `G` | ゴール |
| `h` | 横に巡回する敵 |
| `v` | 縦に巡回する敵 |
| `r` | その場で回り続ける敵 |

視界の長さは `EnemyRange()`、視野角は `FOV`、気配で気づかれる距離は `NEAR_DIST` で調整できます。
